# Feedback and contributions

**Where to PlAI** is maintained by a small team on behalf of **Sharon Tal & Marc Gruber**, the authors of the Market Opportunity Navigator / Where-to-Play method.

## Feedback and bug reports

Open an [issue](https://github.com/Where-2-Play/where-to-plai/issues). Bug reports, unclear wording and ideas from using the plugin are all welcome. For security issues, follow [SECURITY.md](SECURITY.md) instead.

## Pull requests

Pull requests are possible, but please **open an issue first** and describe what you want to change and why, so we can agree on it before you put work into it. [docs/development.md](docs/development.md) explains how the plugin is built and checked.

- **Changes to the framework itself** — renaming factors, altering scoring logic, adding or dropping a worksheet step, reinterpreting the method — need the authors' sign-off.
- **The plugin stays human-in-the-loop.** It never scores or picks the market for the team.
